Appearance

Downloads & background

Fast uses parallel fragments when the source supports them. Your internet connection and the source set the actual speed; direct files may use one connection.

Applies to new or resumed downloads. Pause and resume to apply changes. A speed limit uses one fragment at a time.

Both options are off until you enable them. Notifications use a generic message without video titles or source links.

Updates

Daily engine checks are on by default and can be turned off above. Checks contact the engine publishers without sending your download history. Missing tools repair automatically; upgrades need your click. Downloads must match publisher checksums. Desktop release links require signed release metadata.

No update check yet.

Authenticated release checks need a maintainer signing key in this build.

Your privacy

No account, analytics, advertising SDK, or cloud history. Source links and finished-file locations are kept locally so you can find your downloads. Clearing history does not delete your media files.

TurboSave reads your clipboard only when you press Paste. It does not import browser cookies or passwords.

Diagnostics contain versions and status counts, without links, filenames or local paths. Exporting saves a file on your PC; nothing is uploaded.

Local engines

Checking…

Engines ship with the app. Fetch a newer build when a source changes; support for every website is not guaranteed.
